# Changelog

Notable changes to revl. Versions track the language and toolchain; the IR
contract is versioned separately by `ir_version` (see [docs/stability.md](docs/stability.md)).

## [3.0.0] - unreleased ("live systems")

The first working version: a language whose compiler runs six hardened runtimes,
compiles itself, and admits agent-generated components through the same checker a
human uses. Everything below builds on the frozen v1/v2 core. This section is
still open; the exit gate is in [docs/v2.0-roadmap.md](docs/v2.0-roadmap.md)
under "v3.0 release gate".

### Agent-native effects

- **Witnessed effects.** An `effect` may declare its inverse as a witnessed,
  transactional operation: the mutation persists on a clean session end and
  reverts residue-free on abort, both checked. Filesystem mutations are the first
  catalog. This is a distinct effect classification from `acquire` (a bracket
  that replays on every teardown), not a special case of it.
- **Per-tool-call effects on all six tiers.** A witnessed effect works from a
  provide-method body, so an agent's per-request filesystem mutation is checked,
  persisted, and revertible on every runtime, not only at component activation.
- **The session commit protocol.** Three action classes (witnessed, deferred, and
  immediate) with a two-step hash-bound commit over MCP; the commit target is
  derived from owner-held state, never the current frame. On abort the deferral
  queue is dropped and witnessed inverses replay.
- **Auto-approve-unless-irreversible** (pulled into v3, in progress). The
  permission policy expressed as a type judgment: reversible actions clear, only
  the irreversible tail prompts. The payoff of the witnessed and session-commit
  work.
- **Harness-boundary dogfood** (pulled into v3, in progress). A real agent
  harness's tool layer run through the gate end to end.

### Durability and recovery

- **Write-ahead log and `revl recover` on all six tiers.** A process crash
  mid-session is recoverable everywhere: the tier writes durable discharge
  descriptors (direct file writes on py/go/rust/java, stdout-framed on the
  sandboxed wasm tier), and `recover` replays the declared inverses LIFO from the
  log alone, landing residue-free.
- The WAL resumes its sequence space on reopen instead of resetting, so a
  `--watch` reload can no longer corrupt recovery.

### Six tiers, one language

- The Go tier reaches parity as the sixth backend; all six host tiers now conform
  with **zero real emit gaps** (the only refusals are deliberate limits: the
  i32-only wasm substrate and one Java arrow-type case).
- Cross-tier value marshalling, reactive withdrawal on provider death, and
  `revl run --placement` compose components built for different runtimes in one
  running system across process boundaries.

### Self-hosting

- revl compiles itself. `selfhost/compile.rvl` runs a revl-native pipeline
  (`admit` / `compile_to`, no reference compiler in the chain) whose output is
  byte-identical to the reference, on py and rust. All six tier emitters are
  written in revl and cross-checked byte-for-byte against their references, and
  the selfhost emitters were restored to byte-identity after the witnessed and
  compensation changes (the differential oracle is intact).

### Live systems

- `revl swap` migrates a live component across tiers, `revl why` explains a
  runtime transition with a prediction-vs-actuality oracle, and `revl apply`
  executes a plan with derived rollback. A scripted demo runs the whole sequence
  from a clean checkout.

### Conformance and tooling

- An autogenerated conformance and performance matrix, gated against drift in CI,
  measuring every construct through every backend and handing each tier's output
  to that tier's real compiler (`tsc`, `cargo check`, `javac`, `wasmtime`, a
  scope walk for Python).
- A ruff F-level lint gate and a playground-wheel freshness gate.

### Fixed

- The A5 compensation contract is two-phase: a compensation is discharged on a
  clean unload and runs only on abort, in a second phase after proof replay. The
  conformance TCK is being brought in line with this (pulled into v3).
- The cross-seam async-forwarding path (pulled into v3, in progress).

## [2.0.0]

The 2.0 language on the frozen v1 core: a TypeScript-subset stratum of pure
functions, ADTs with exhaustiveness-checked `match`, modules, template strings,
`extern` host blocks, realms and interception, and a specified stdlib. See
[docs/syntax-2.0.md](docs/syntax-2.0.md).
