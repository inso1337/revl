# revl 2.0 — implementation roadmap

**Branch:** `v2.0` · **Design:** docs/syntax-2.0.md · **Status:** in progress

`v2.0` = realms/interception (already merged, `ir_version: 2`) **plus** the
full-language proposal in syntax-2.0.md — the pure-expression stratum grows
into a self-hosting-capable language without weakening G1–G8.

## IR versioning (the contract)

| ir_version | carries | backends |
|---|---|---|
| 1 | v1 documents | all — frozen, byte-identical |
| 2 | realms/interception (`isolate`/`intercept`) | cordis-py; TS/wasm reject by version |
| 3 | full-language (`fn`, `type`, `match`, `extern`, `test`) | cordis-py first; TS/wasm follow |

A document's `ir_version` is the *maximum* feature tier it uses. v1 sources
must keep emitting `ir_version: 1` byte-identically (the frozen-reference
invariant) and their goldens must never regenerate.

## Dependency-sorted plan

Each item is independently shippable and gated by what precedes it.

1. **Lexer** — multi-char operators (`== === != !== && || <= >= => ?. ??`),
   single operators (`+ - * / % < > ! ? ; | @`), new keywords (`type use pub
   var while for of if else match test assert async as`).
2. **Types & data (§2)** — `type` declarations: structural records, generics
   `[]`, enums (no payload), ADTs (payloads); built-ins `Opt[T]`/`List[T]`/
   `Map[K,V]`/`Result[T,E]`; `T?` sugar. Checker: structural subtyping.
3. **Functions & expressions (§3.1–§3.5)** — top-level `fn`/`pub fn`, the
   TS-subset expression layer (operators, `if`, `let`/`var`, `while`/`for-of`,
   arrows, records, lists, calls, indexing, destructuring), `==`/`===`
   equivalence, the §3.3 exclusion diagnostics.
4. **`match` (§3.3)** — exhaustiveness-checked ADT eliminator.
5. **Modules (§1)** — `use`/`pub`, module-private by default, import-cycle check.
6. **Services 2.0 (§5)** — `async fn`, `commutative`.
7. **Components 2.0 (§4)** — block-effect form, `fail` (L-Raise).
8. **Host blocks (§6)** — `extern pure|acquire|emission fn … = @ts {} = @py {}`,
   mandatory classification, G8 audit surface.
9. **`verified` & `test` (§7)** — `revl test` runner, totality tier.
10. **Migration (§9)** — `"$name"` → `` `${name}` `` templates (mechanical,
    one release, touches examples + IR).

## Invariants (checked every step)

- v1 goldens byte-identical; frontend/backend-py/backend-ts suites green.
- Every new rejection lands in `examples/rejections/` and joins the executable
  spec (`tests/test_frontend.py` REJECTIONS).
- Error messages are a deliverable (DESIGN §9): each names its guarantee and
  the fix.

## Parallelization seams

Once (1)–(3) fix the AST/IR interfaces, the later items are mostly independent
and can run on separate branches: `match` (4), `use` (5), `extern` (8),
`test`/`verified` (9) each touch disjoint parser/lower regions; TS/wasm backend
parity for realms, then for full-language, is backend-local.
