All three reported bugs reproduced on `a240281e` before the fix. THE TYPE ENVIRONMENT WAS BEING ASKED "IS THIS NAME BOUND?" WHEN IT ONLY ANSWERS "WHAT TYPE DOES THIS NAME HAVE" (2026-10-05; issues #1903, #1924, #1909; frontend resolver, `src/revl/typecheck.py`).** The frontend carries one dict of name -> type and nothing else, so a name that is *absent* is the only representation of "unbound", and every path that forgot to record a local silently fell through to the module tables in `ExprVar`: the nullary-ADT case first, then item 380's rule that a bare reference to a top-level `fn` is a first-class function value typed `(params) -> returns`. Two such paths existed and account for every one of the three reports. First, `ExprMatch` (in both `infer_ast` and `check_ast`) bound an arm payload only when `_scrutinee_spec(types, scrutinee_t)` returned a user `variant` spec; the built-in `Opt[T]`/`Result[T, E]` have no such entry, so `Some(_)`/`None`/`Ok(_)`/`Err(_)` payloads were dropped, the arm body inferred `Never`, and `join(None, t)` collapsed the whole match to `None`. That is #1903 in one spelling — `let names = match xs { ... }` then `names == "[]"` reported "`==` cannot compare `(Int) -> List[Str]` with `Str`", the arrow being a same-named top-level `fn names` the untyped local had fallen through to — and #1909 in another: a `match` over a `List[Str]` with an `[]` arm bound `List[Never]`, so a following `indexOf(k)` was refused with "builtin `indexOf` argument expects `Never`, got `Str`". (issue #1983) **✅ FIXED (2026-10-05; PR #1993, written while the branch is queued for the merge train, so this item cites no merge sha).** A PERSISTED ORIGIN NOW SURVIVES THE HOST ROUND TRIP: `fetch -> write -> read -> announce` was ADMITTED under the default trusted-author profile while the direct `fetch -> announce` was refused at `mem.rvl:7`, because `read`'s declared return is a plain `Str`, so the reloaded value entered the body clean and the host boundary laundered the origin — the edge `docs/design/249-taint-provenance.md` leaves unmodelled when it scopes the no-false-clean invariant *within a body* and lists Slice B's coverage as the turn's own fns/records/collections/state/relay (H16, provenance-carrying memory, is unbuilt, so no `external` node ever carried the origin across). This is the issue's option 1 and the reason it could be done exactly: the reload is not invisible, it is a call whose ARGUMENT names the resource, so the fix is a per-resource fixpoint on the WRITER side rather than a stronger value lattice. `_FlowChecker` gained a `scope_writes` table keyed `(scope, extern)` — `scope` being `retention.persistence_sink_of`'s dotted capability head — filled by `_record_scope_write` from `_taint_of_call` (a direct `emit write(p, v)`) and from `_on_persistence` in every mode (so a write routed through a helper or a service op is recorded too), and READ by `_mint_reload`, which joins the recorded origins onto the reload's RESULT only — never back into `self.env` — appending the read as one more chain step so the EXISTING G9 raise site reports the whole path with no new one: `The tainting path is fetch() -> write -> read -> announce.` Three things make it exact rather than approximate. It is FLOW-INSENSITIVE by construction, because `_infer_scope_env` sweeps every body of the program non-enforcing, to a fixed point, BEFORE any refusal pass, so reordering write and read inside a body cannot defeat it — `let v = read(p)` written above the write is refused identically, which a per-body walk would miss and which is the whole point of paying for the fixpoint. It joins both lattices to a JOINT fixed point rather than one, because the table decides what a read mints and a signature decides which writes a caller records, so `check_taint` alternates `_infer_scope_env` with `_infer_signatures` — which now also carries the table, so a body whose ONLY effect is a reload records the scope's origins in its own `mints` — until a combined monotone measure stops growing; that closes the seam residual a per-body table leaves open, where a provide-method wrapper that only reloads a resource and is called from another component was still ACCEPTED. And it records CONCRETE origins only (a symbolic parameter marker is inference bookkeeping, not authority, and would poison the table) while `_mint_reload` never re-mints a persistence sink's OWN argument, which is what keeps `read -> write` and the corpus's reader-less sibling sinks admitted (`demo/components/services.rvl` declares `emission[db] fn execute(sql: Str) -> Int` beside `emission[db] fn put(key: Str, value: Str)` with no reader extern at all — refusing those would have been the over-refusal this change was built around, and the census is the evidence it was not hit). The mechanism is INERT when the program declares no persistence scope, so ordinary programs are byte-identical, which is why the census still buckets all 1264 published programs identically (`census verify --strict`: the committed artifact is current). Pinned by `tests/test_taint_persistence_roundtrip_1983.py` (12 tests: the round trip refused with its chain named, reordering refused, the wrapper loader refused at its caller, plus five shapes that must STILL be admitted), proved RED by reverting only `src/revl/taint.py` (5 failed, 7 passed) and GREEN after (12 passed), with 464 passed and 6 skipped across the taint, persistence and G9 selectors. STILL OPEN, STATED: the join is per `(scope, extern)` PAIR and not per path, so `write("p", v)` followed by `read("other/page")` is still refused — the conservative side of the same flow-insensitivity, and path keying is provenance-carrying memory (H16) rather than this item; and no self-host twin applies, because `selfhost/*.rvl` does not port the origin lattice, G9 or `endorse`'s flow walk.

(issue #1912) **✅ FIXED (2026-10-05; written while the branch is queued for the merge train, so this item cites no merge sha).** A SERVICE OPERATION CAN NOW DECLARE THE CLASS ITS PROVIDER MAY REACH, NOT ONLY THE CLASS ITS CALLERS MUST MARK: `witnessed[store] fn set(v: Str) -> Str` is now a legal service declaration, admitted when the implementation reaches nothing but witnessed (reversible) effects and REFUSED the moment it reaches a true `emission`, with a repair that names what it actually reached.
