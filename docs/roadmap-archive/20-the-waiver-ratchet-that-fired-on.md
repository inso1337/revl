## The waiver ratchet that fired on `main`

541. ✅ **THE ITEM-130 STREAM WAIVER OUTLIVED THE GAP THAT CLOSED IT, AND `main` WENT RED ON A TABLE WHOSE CORRECT MOVE IS DELETION (2026-09-20, found while landing the merge train; issue #1211).** `NATIVE_GATE_GAPS` in `tests/test_selfhost_compile.py` is the **refusal** half of the ratchet pair that watches the native frontend: it holds each document the reference admits and `selfhost/lower.rvl` does not, pinned to the exact verdict the gate returns for that document, and the test that reads it fails whenever the verdict becomes `""`. The comment above the table states why that is the design and not an accident — "the day `selfhost/lower.rvl` grows the grammar, the native gate returns `""` and this test fails on the stale entry instead of quietly keeping a waiver nobody rereads" — and the failure message states the remedy in the same terms: *"If the self-host grammar landed, DELETE the entry."* Its one remaining entry named `emit_rust_corpus/comp_stream.rvl` at a verdict reading *`sub` is not a declared requirement of `Parked`*, and the paragraph beside it had already diagnosed the gap as **not the document's**: a `subscribe` acquisition's bind never reached the component scope that `call_head_declared` resolves call heads against, so the later `sub.next()` read as an undeclared access and drew the shared G1 code — the identical verdict the tree's own `backends/rust/scenarios/stream.rvl` drew, which is what made it a `lower.rvl` gap that the first stream document in the emit corpus merely made visible. **#1139 closed it** — its own title records the item-130 stream statement forms taking those false-reject and G1 verdicts to zero — and left the waiver behind, so `876defef` failed the `ci` run it pushed: `test_native_gate_admits_the_whole_emit_surface` is the single failure in a 16052-passed `root-suite-affected` **and** in `frontend (3.12)`, one red wearing two job names. It is not one of the seven required contexts, which is exactly why it was worth an issue rather than a quiet deletion: it reddens the broad suite of every open PR while blocking no merge, so the failure surfaces as N unrelated broken branches instead of one broken main. The fix is the deletion the table asks for, with the residual the document still is — a **byte** divergence in the fully-native chain, now that the gate admits it and the chain builds rust for it — left named where it is already measured, in `LOWER_GAP_DOCS`, whose test compares emitted text rather than verdicts. Stated for the next reader, because both tables name the same document and only one was stale: a closed **refusal** is deleted from `NATIVE_GATE_GAPS`, while a **byte residual** leaves `LOWER_GAP_DOCS` only when the text matches, and conflating the two either hides a real divergence or keeps a waiver after its gap closed. `tests/test_selfhost_compile.py` goes from 1 failed to 195 passed.
