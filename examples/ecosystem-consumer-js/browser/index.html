The revl admission gate, in this browser tab

No server round trip and no Python: this page loaded the revl:gate@1.0.0 wasm component, transpiled by jco, and calls admit(source) in process. What it demonstrates is the double enforcement: the gate decides, and the substrate enforces, and neither trusts the other's absence.

This gate issues no admissions

It decides the composition and guarantee layer (G1–G4, A1, PRELUDE, and parse failures as BAD) and not the reference type layer, so admitted is false on every arm and its non-refusing arm means “found nothing I am able to refuse”, never “admitted”. There are exactly two safe readings: REJECT on refused, ESCALATE on no-objection and outside-frontier.

Layer 1 — the decision

The gate reads the candidate's source. A refusal is authoritative and byte-agrees with the reference compiler, so the artifact is never fetched, never compiled, never instantiated.

2

The escalation gap

A non-refusal is not an admission, so loadOrRefuse has no code path that instantiates on this gate's word alone: without a reference verdict it throws EscalationRequired. There is no flag to skip it. In production this box is revl compile or revl.gate.admit answering over the network (or Pyodide, which is the browser's full-coverage fallback); here it is a checkbox, so you can watch what changes.

3

Layer 2 — the substrate

The artifact declares its reach as wasm imports. The host instantiates it with an import object shaped by the policy and nothing else, so an ungranted reach is a missing import and the engine refuses to instantiate. That refusal is not this page's code and not the gate's: uncheck a capability the artifact needs and watch WebAssembly.instantiate do it.

not instantiated

What this page is not

A verdict is a decision, not a confinement, and this gate covers the self-host frontier rather than the whole reference language: the frontier above is part of the verdict, and a verdict cached from this tier must never be served to a reader of the py tier's. A trap inside the component is not a verdict either; treat it as “no verdict reached” and fail closed. Full contract: docs/gate-dependency-contract.md.
